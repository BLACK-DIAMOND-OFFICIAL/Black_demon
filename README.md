# Black Demon

**Black Demon** is a secure and anonymous penetration testing framework developed by **Black Diamond**. It is built for professionals and researchers who require stealth, modularity, and flexibility in their cybersecurity tools.

## Important Notice

> **Black Demon does not come with any built-in modules.**  
> Modules are sold separately by Black Diamond as independent add-ons.  
> This ensures maximum customization and control for the user.

## Features

- Anonymous operations via integrated Tor routing
- Create and test your own custom modules
- Supports multiple programming languages (Python, C, C++, Ruby, Bash, Java)
- Lightweight and flexible CLI-based interface
- Expandable with commercial modules

## Requirements

- Python 3.10 or higher  
- Tor installed and configured  
- Git  
- Linux or Windows (Linux recommended)  
- Root/Administrator access (for certain operations)
